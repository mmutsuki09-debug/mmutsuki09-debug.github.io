choyoyaku プライバシーポリシー

choyoyaku(以下「本アプリ」)は、開発者本人が自分の YouTube チャンネルに動画をアップロードするためだけに使う個人用ツールです。

取得する情報

  • 開発者本人の Google アカウントによる認証情報(YouTube への動画アップロード権限)のみ。
  • 開発者以外のユーザーの情報は、取得・保存しません。

利用目的

開発者本人の YouTube チャンネルへの動画のアップロード(タイトル・説明文・サムネイルの設定を含む)のみに利用します。

第三者への提供

取得した情報を、第三者へ提供・共有・販売することは一切ありません。

Google API サービスのユーザーデータ

本アプリによる Google API から受け取った情報の使用および他のアプリへの転送は、限定使用の要件を含む Google API サービスのユーザーデータに関するポリシーに準拠します。
